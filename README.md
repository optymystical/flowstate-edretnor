# Flow State: The Fall of Edretnor

The Flow State starter campaign as a Foundry VTT module (Foundry v14, Flow State system 0.93.0+): one Adventure holding the
tournament at Edretnor, its festival, the cult attack, the escape through the city and the audience with the king.

## Install (private testing)

1. Copy or clone this repository into your Foundry `Data/modules/flowstate-edretnor` folder.
2. In a Flow State world, enable **Flow State: The Fall of Edretnor**.
3. Reload the world: the module offers to import the Adventure (or open the compendium **The Fall of Edretnor** and click Import). Importing also sets the world to a level-0 start
   (Shards with a 100 starting purse, Common Grade 3 starting gear).
4. Open the journal **Start Here: The Fall of Edretnor**.

## Building

The Adventure is built from `src/` (`cd dev && npm install && npm run build`). Close the world in Foundry before rebuilding.
